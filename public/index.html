Learn Node on Node

This site teaches Node.js, and it is built with Node.js. Every page you read here was sent to you by the server it describes, and every lesson has a live demo running on that same server.

How this site works

When you open a page, your browser sends a request to a small Node.js program called server.js. The server looks at the path you asked for, finds the matching file in its public folder, and sends it back. When you click Run the demo on a lesson, the server runs real code and answers with JSON.

The site uses no npm packages. Everything comes from modules that ship with Node.js itself.
